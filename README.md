# Roller Coaster Dynamics Lab

## Files
- `PROJECT_REPORT.md` — full project report draft
- `physics_model.py` — physics engine
- `roller_coaster_colab.py` — Google Colab workflow
- `app.py` — Streamlit dashboard
- `survey_questions.txt` — social-media/Google Forms survey
- `survey_analysis.py` — survey analysis template
- `requirements.txt` — Python packages

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Google Colab
Upload `physics_model.py` and `roller_coaster_colab.py` to Colab, then run the notebook cells in order.

## Important
This is a preliminary/educational model, not a ride-certification or engineering approval system.
